# Bruno Milano static homepage

Pure HTML, CSS and vanilla JavaScript. No React, bundler, npm, or framework dependency.

## Files
- `index.html` — page markup
- `css/styles.css` — all page styles
- `js/script.js` — vanilla JavaScript interactions, including Desktop/Mobile preview toggle
- `assets/` — 27 extracted image assets referenced by the page

## Run
Open `index.html` directly in a browser, or serve the folder with any static web server.

Example:
```bash
python3 -m http.server 8080
```
Then open `http://localhost:8080`.
